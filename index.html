Introduction

Git is a distributed version control system. It records changes to your files over time so you can recall specific versions later.

Every copy of a project contains its full history, which means you can work offline and still commit, compare and review changes.

This guide covers the commands you need for everyday work:

  • Installing Git on your computer
  • Creating a repository
  • Saving snapshots with commits
  • Working in parallel with branches
Installation

Most systems can install Git through a package manager. On Debian and Ubuntu, run the following command in a terminal: 

sudo apt install git

After the install finishes, confirm it worked by checking the version with git --version.

Creating a Repository

A repository is a folder that Git tracks. Move into your project folder and initialize it: 

git init

To copy an existing project instead, use git clone followed by the repository address.

Useful things to know right after creating a repository:

  • A hidden .git folder stores the history
  • Deleting that folder removes all version tracking
Making Commits

A commit is a saved snapshot of your project. First choose which changes to include by staging them: 

git add index.html

Then record the snapshot together with a short message:

git commit -m "Add home page"

Run git status at any time to see which files are modified, staged or untracked.

Branching and Merging

Branches let you develop a feature without touching the main line of work. Create and switch to a new branch in one step: 

git switch -c new-feature

When the feature is ready, return to the main branch and merge:

git merge new-feature

A healthy branching habit looks like this:

  • Keep each branch focused on one task
  • Commit small and often
  • Delete branches once they are merged
